## 🔒 Security & Credential Protection

Before uploading to your Maker ESP32:
1. Update `ssid` and `password` with your 2.4GHz Wi-Fi credentials.
2. Update `BOTtoken` with your HTTP API token from `@BotFather`.
3. Update `CHAT_ID` with your numeric user ID from `@myidbot`.

> ⚠️ **Important:** Keep a backup copy of your original working sketch before making any AI-generated changes!
